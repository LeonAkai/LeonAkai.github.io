アプリについてプライバシー利用規約

プライバシーポリシー

更新日：2026年10月7日

OpenClaw 日記アシスタントは、LeonAkaiが自分の日記を作成するために利用する個人用アプリです。

取得する情報と目的

  • Googleカレンダー：本人が許可したカレンダーの予定のタイトル、日時、説明、場所など、APIが返す予定情報を参照します。当日の予定を手がかりに質問を作るために使います。
  • Googleアカウント：メールアドレスなどの認証・識別情報と認証トークンを、本人のカレンダーへの接続に使います。
  • Notion：日記の記入状況、タイムボクシングやタスクを読み、振り返りの作成と日記の保存に使います。
  • Discord：本人の回答とメッセージ情報を、インタビューの継続と日記の作成に使います。

AI処理と外部サービスへの送信

当日の予定情報、Notionの関連情報、本人の回答は、OpenClawに接続されたAIサービスで質問や日記を作るために処理されます。現在の構成ではOpenAIのCodexを利用します。必要な情報はそのAIサービスに送信されます。

質問や保存結果は指定のDiscordチャンネルに送られ、そのチャンネルの閲覧権限を持つ人が閲覧できます。本人が話した出来事をまとめた日記は、指定のNotionページに保存され、そのページの共有設定に従って閲覧できます。

Google、OpenAI、Discord、Notionでは、それぞれの規約・プライバシーポリシー・契約設定に従って情報が処理されます。

保存と削除

認証情報、会話の進行状態、実行履歴などは運営者のMacや利用サービスに保存されます。Googleの認証情報はMacのキーチェーンに保存します。Notion・Discordの認証情報は1Passwordで管理します。

現在、自動で一定期間後にすべての記録を削除する機能はありません。本人はNotionの日記、Discordのメッセージ、Macの会話履歴・実行履歴を各保存先で削除できます。各サービスのバックアップや保持期間は、そのサービスの規定に従います。

アクセスの停止

本人はGoogleアカウントの第三者への接続設定で本アプリへのアクセスを解除できます。以後のGoogleカレンダー取得を停止します。アクセスの解除だけでは、すでに保存された日記や会話履歴は削除されません。

Googleデータの利用制限

本アプリのGoogle APIから受け取った情報の利用と他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。本アプリの目的は本人の日記作成の支援に限ります。運営者はGoogleデータを販売したり、広告配信や汎用AIモデルの学習目的に利用したりしません。

この公開サイトについて

この説明サイトはGitHub Pagesで配信します。GitHubはセキュリティのため訪問者のIPアドレスを記録します。詳細はGitHubのプライバシー声明をご覧ください。このサイトには独自のアクセス解析や入力フォームを設置していません。
